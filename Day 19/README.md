# Student Grade Management System

A simple C program that calculates and displays a student's grade based on the marks entered by the user. The program uses conditional statements to assign grades and demonstrates basic C programming concepts.

## Features
- Accepts student name and marks
- Calculates grade automatically
- Displays student details and result
- Uses if-else conditions

## Technologies Used
- C Programming
- Conditional Statements
- Input/Output Functions

## Example

Input:
Name: Harshita
Marks: 85

Output:
Grade: A

# Number Guessing Game

A fun C programming game where the computer generates a random number between 1 and 100, and the player tries to guess it. The program provides hints after each guess and tracks the number of attempts.

## Features
- Random number generation
- User interaction through input/output
- Hint system (Too High / Too Low)
- Attempt counter

## Technologies Used
- C Programming
- Loops
- Conditional Statements
- Random Number Generation

## Example
Input: 50, 75, 63
Output: Congratulations! You guessed it in 3 attempts.
