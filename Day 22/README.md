# C Programming Mini Projects

This repository contains basic C programming mini projects created for learning and practice. These programs help in understanding important programming concepts such as loops, arithmetic operations, conditional statements, and number-based logic.

## Projects Included

### 1. Armstrong Number Checker
This program checks whether a number entered by the user is an Armstrong number or not. An Armstrong number is a number in which the sum of the cubes of its digits is equal to the original number, such as 153.

**Concepts used:**
- `while` loop
- arithmetic operations
- conditional statements
- digit extraction using modulus and division

### 2. Factorial of a Number
This program calculates the factorial of a number entered by the user. Factorial is the product of all positive integers from 1 up to the given number.

**Concepts used:**
- `for` loop
- multiplication logic
- user input and output
- variables and arithmetic operations

## Technologies Used
- C Programming
- Standard Input/Output functions
- Loops
- Conditional Statements
- Arithmetic Operations

## Purpose
These mini projects were created to strengthen basic C programming concepts and improve problem-solving skills through simple practical examples.
