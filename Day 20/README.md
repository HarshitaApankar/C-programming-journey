# Electricity Bill Calculator

A C program that calculates the electricity bill based on the number of units consumed using slab rates.

## Features
- Takes unit consumption as input
- Applies different billing slabs
- Calculates total bill amount
- Demonstrates conditional statements in C

# Voting Eligibility Checker

A simple C program that checks whether a person is eligible to vote based on age entered by the user.

## Features
- Takes user name and age as input
- Checks voting eligibility
- Displays the result
- Uses conditional statements and basic input/output
