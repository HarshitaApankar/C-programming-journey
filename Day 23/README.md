***C Programming Practice

This repository contains C programs that demonstrate the use of arrays, strings, loops, and conditional statements. These examples are designed to strengthen problem-solving skills and provide hands-on practice with fundamental C programming concepts.

***Programs Included
***1. Matrix Addition
Accepts two 2×2 matrices from the user.
Adds the corresponding elements of both matrices.
Displays the resulting matrix.

***Concepts Covered
Arrays and Two-Dimensional Arrays
Strings and String Functions
Loops (for)
Conditional Statements (if-else)
User Input and Output
Basic Algorithm Design

These programs are part of my C programming practice and help build a strong foundation in problem-solving and programming logic.

***2. Prime Number Check
Determines whether a given number is prime or not using conditional statements and loops.
Concepts Covered
Variables and Data Types
Input and Output (printf and scanf)
if-else Statements
for Loops
Arithmetic Operators

These programs are part of my C programming practice and help strengthen fundamental programming skills.
