# C Programming Mini Projects

This repository contains basic C programming mini projects created for learning and practice. The programs focus on fundamental programming concepts such as user input, loops, arithmetic operations, and conditional statements.

## Projects Included

### 1. Palindrome Number Checker
This program checks whether a number entered by the user is a palindrome or not. A palindrome number is a number that remains the same when its digits are reversed, such as 121 or 1331.

### Main:
r=n%10
rev=rev*10+r
n=n/10

**Concepts used:**
- `while` loop
- arithmetic operations
- conditional statements
- reversing a number

### 2. Simple Interest Calculator
This program calculates the simple interest using the formula:

**Simple Interest = (Principal × Rate × Time) / 100**

The user enters the principal amount, rate of interest, and time period, and the program displays the calculated simple interest.

**Concepts used:**
- user input and output
- arithmetic calculations
- variables and formulas

## Technologies Used
- C Programming
- Standard Input/Output functions
- Loops
- Conditional Statements
- Arithmetic Operations

## Purpose
These programs were created to strengthen basic C programming concepts and improve problem-solving skills through simple practical examples.
